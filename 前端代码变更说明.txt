========================================
AI 小说精修工作台 - 前端代码变更说明
========================================
（随 GitHub 提交附带的说明文档，供审阅前端代码改动）

一、前端文件构成
----------------------------------------
- static/index.html   页面结构（三栏工作台 + 各类弹窗面板）
- static/css/style.css  样式（浅色主题、卡片/批量/世界书等模块样式）
- static/js/app.js    全部前端逻辑（原生 JavaScript，无框架依赖）

二、前端主要功能模块
----------------------------------------
1. 三栏布局工作台
   - 左栏：小说列表 / 章节目录 / 向量记忆检索 / 文本检索 / 查找替换 / 总体设定修改（批量）/ 读书模式
   - 中栏：章节卡片编辑器（原文 vs 修改版 逐段对照、插入段落、保存/审校/重索引）
   - 右栏：修改 Agent（全局指令 / 自定义 Agent / 槽位保存）、Chat 助手、设定摘要（世界书）
   - 底部：修改要求输入 + 改写选中段 / 整章批量改写
2. 视图切换：卡片视图 / 整页视图 / 对比视图（diff）
3. 章节编辑
   - 保存提速：后端章节文件采用紧凑 JSON，前端保存流程同步优化
   - 标题自动标记：内容被 AI 修改后自动为标题追加【已修改】后缀（去重）
   - 章节名编辑按钮（✏️）
4. AI 修改交互
   - 改写选中段（SSE 流式渲染）
   - 多段统一改写 / 整章批量改写（一次调用通读全文）
   - 进度面板（progress panel）：实时显示阶段与取消按钮
5. 总体设定修改（批量）
   - 模式选择：keyword（关键词触发）/ all（全章节逐章）
   - 修改要求 + 章节范围输入（支持"全部"按钮）
   - 进度条实时显示：阅读/预思考/修改中/跳过 N 章
   - 待确认列表：保留全部 / 放弃全部 / 逐条保留与放弃
   - 历史记录（重新修改入口）
6. 世界书（Lorebook）
   - 设定摘要面板：条目列表（名称/分类/触发词/内容）、编辑弹窗、测试命中
   - 读书模式：章节选取（多选/范围输入）、AI 逐章阅读进度
7. 文本检索与查找替换
   - 文本检索：关键词命中章节 + 上下文片段；标题命中标注（含标题）
   - 查找替换：预览命中（正文 X 处 + 标题 Y 处）→ 执行替换；确认文案注明正文与标题同步替换、不加【已修改】
8. 外部 API 多槽位
   - 设置 → 外部API 面板：配置槽位下拉（新建/删除/切换），每套独立保存
   - 顶部状态栏显示当前槽位与连接状态（如：外部API已连接[default]）
   - 连接测试 / 列出模型（含 /models 不可用时的降级提示）
9. AI 供应商切换（本地Ollama / 外部API）
10. 其他：导出修改版、专注模式、Prompt 仓库、设置弹窗（AI 参数/外部API/Prompt 仓库）

四、技术说明
----------------------------------------
- 纯原生 JavaScript + XMLHttpRequest 实现 SSE 流式（sseRequest），支持取消
- API 统一封装 api()：先 res.text() 再 JSON.parse 兜底，避免 HTML 错误页导致解析失败
- CodeMirror 用于编辑器（markdown 模式）
- 所有 AI 修改请求带 chapter_idx / chapter_title，保证 AI 章节感知
