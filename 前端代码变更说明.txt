========================================
AI 小说精修工作台 - 前端代码变更说明
========================================
（随 GitHub 提交附带的说明文档，供审阅前端代码改动）

一、前端文件构成
----------------------------------------
- static/index.html   页面结构（三栏工作台 + 各类弹窗面板）
- static/css/style.css  样式（浅色主题、卡片/批量/世界书等模块样式）
- static/js/app.js    全部前端逻辑（原生 JavaScript，无框架依赖）

二、前端主要功能模块
----------------------------------------
1. 三栏布局工作台
   - 左栏：小说列表 / 章节目录 / 向量记忆检索 / 文本检索 / 查找替换 / 总体设定修改（批量）/ 小说转世界书
   - 中栏：章节卡片编辑器（原文 vs 修改版 逐段对照、插入段落、保存/审校/重索引）
   - 右栏：修改 Agent（全局指令 / 自定义 Agent / 槽位保存）、Chat 助手、设定摘要（世界书）
   - 底部：修改要求输入 + 改写选中段 / 整章批量改写
2. 视图切换：卡片视图 / 整页视图 / 对比视图（diff）
3. 章节编辑
   - 保存提速：后端章节文件采用紧凑 JSON，前端保存流程同步优化
   - 标题自动标记：内容被 AI 修改后自动为标题追加【已修改】后缀（去重）
   - 章节名编辑按钮（✏️）
4. AI 修改交互
   - 改写选中段（SSE 流式渲染）
   - 多段统一改写 / 整章批量改写（一次调用通读全文）
   - 进度面板（progress panel）：实时显示阶段与取消按钮
5. 总体设定修改（批量）
   - 模式选择：keyword（关键词触发）/ all（全章节逐章，AI 自判是否修改）
   - 修改要求 + 章节范围输入（支持"全部"按钮）
   - 进度条实时显示：预思考方案/修改中/已跳过 N 章
   - 独立开关：同步更新世界书（默认关，省 token）/ 同步向量记忆（默认开，不耗 AI token）
   - 待确认列表：保留全部 / 放弃全部 / 逐条保留与放弃
   - 历史记录（重新修改入口）
6. 世界书（Lorebook / 小说转世界书）
   - 设定摘要面板：条目列表（名称/分类/触发词/内容）、编辑弹窗、测试命中、整理去重
   - 世界书总结模板下拉：详细梳理版 / 简洁版 / 剧情推进版
   - 关键词定向总结：输入实体名，全文检索相关章节 → AI 总结该设定写入世界书
   - 小说转世界书：章节选取（多选/范围输入）+ 9 类提取分类勾选（角色/地点/组织/物品/种族/世界观/剧情/关系/知识书）
7. 文本检索与查找替换
   - 文本检索：关键词命中章节 + 上下文片段；标题命中标注（含标题）
   - 查找替换：预览命中（正文 X 处 + 标题 Y 处）→ 执行替换；确认文案注明正文与标题同步替换、不加【已修改】
8. 外部 API 多槽位
   - 设置 → 外部API 面板：配置槽位下拉（新建/删除/切换），每套独立保存
   - 顶部状态栏显示当前槽位与连接状态（如：外部API已连接[default]）
   - 连接测试 / 列出模型（含 /models 不可用时的降级提示）
9. AI 供应商切换（本地Ollama / 外部API）
10. 其他：导出修改版、专注模式、Prompt 仓库、设置弹窗（AI 参数/外部API/Prompt 仓库）

三、近期关键变更记录
----------------------------------------
v3.1（本次提交）
- 修改 Agent 面板重构为三个分块：全局修改指令 / 自定义 Writer Agent（每本小说独立）/ 文风要求
- 文风要求分块：可自主添加多个、每个可单独开关、同级优先级一并生效、全局跨小说保存；支持编辑与删除（通用编辑弹窗）
- 槽位保存改为全局跨小说（上限 50 个），新增「🖊️ 管理」：可编辑 / 删除已存槽位
- 全局修改指令、自定义 Writer Agent、底部修改要求回归每本小说独立；仅槽位与文风要求跨小说
- 多模型协作：小说转世界书面板新增「世界书生成模型」下拉，批量修改面板新增「批量修改模型」下拉（沿用当前 / 本地 Ollama / 外部 API 槽位），选择全局跨小说保存
- 批量修改跳过保护：修改失败 / AI 返回原文（无实质修改）也立即标记「已跳过」，不再停留在"修改中"假象
- 小说转世界书进度显示「已总结 N 批」「最近批次 +N 条 / 失败原因」

v3.0（上一提交）
- 读书模式 → 小说转世界书：新增 9 类世界书提取分类勾选（角色/地点/组织/物品/种族/世界观/剧情/关系/知识书）
- 世界书总结模板下拉（详细/简洁/剧情），读书/批量/关键词总结统一使用
- 世界书关键词定向总结：输入实体名 → 全文检索 → AI 通读总结该设定写入世界书
- 批量修改：新增「同步更新世界书」「同步向量记忆」独立开关（世界书默认关省 token；向量记忆纯代码不耗 token）
- 批量修改：AI 判定跳过/规划出错/关键词未命中即立即标记「已跳过」，不再进入修改阶段（不再显示"修改中"假象）
- 批量修改规划与修改阶段注入前后章节上下文，保证相邻章节衔接
- 世界书触发读取修复：修改阶段用整章内容匹配触发词，关键词出现在章节中后段也能自动读取相关设定
- 向量记忆中文检索修复：叠加关键词精确匹配，中文词汇可直接命中（英文 embedding 失效的替代方案）
- 世界书 content 强制总分结构（# 标题 + 1.2.3 列举 + 先概括再-细分 + 禁粗体）
- 页面初始化按供应商显示连接状态（外部 API 时直接检查外部连接）

v2.x（上一提交）
- 章节保存提速 + 批量修改异步向量索引
- 单章保存后原文同步为修改版（所见即所存）
- 标题【已修改】自动标记；词汇替换不触发标记
- 查找替换支持标题同步替换 + 标题命中预览
- 文本检索支持标题命中标注
- 批量修改增加全章节模式（AI 自行判断是否修改，跳过无需修改章节）
- 批量进度实时显示"跳过 N 章"
- 外部 API 多槽位 UI（新增/删除/切换，状态栏显示当前槽位）
- 外部 API 连接检测 404 自动降级（chat/completions 验证）
- 世界书条目去重合并、触发词清洗
- 读书模式章节选取（多选 + 范围）

四、技术说明
----------------------------------------
- 纯原生 JavaScript + XMLHttpRequest 实现 SSE 流式（sseRequest），支持取消
- API 统一封装 api()：先 res.text() 再 JSON.parse 兜底，避免 HTML 错误页导致解析失败
- CodeMirror 用于编辑器（markdown 模式）
- 所有 AI 修改请求带 chapter_idx / chapter_title，保证 AI 章节感知
- 世界书分类模板与提取分类由后端动态注入 prompt（前端仅传递分类勾选）
