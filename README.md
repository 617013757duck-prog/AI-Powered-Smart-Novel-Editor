# AI 小说精修工作台（AI-Powered Smart Novel Editor）

一款**本地运行**的 AI 小说精修工具。导入 TXT 小说后，可逐章/批量调用 AI 进行改写、加料、润色；支持向量记忆、关键词触发式世界书设定、纯文本检索与查找替换。AI 引擎可选**本地 Ollama** 或**外部 OpenAI 兼容 API**（支持多套配置槽位，可随时切换）。

---

## 一、功能特性

### 1. 小说导入与章节解析
- 一键导入 TXT 小说，自动识别"第X章""序章/楔子"等章节标题并切分段落
- 支持 utf-8 / gbk / gb18030 / big5 编码自动检测
- 每本小说独立存储，可随时删除、重新导入

### 2. 三栏工作台
| 区域 | 内容 |
|---|---|
| 左栏 | 小说列表、章节目录、向量记忆检索、文本检索、查找替换、总体设定修改（批量）、小说转世界书 |
| 中栏 | 章节编辑器（原文 / 修改版 卡片对照、插入段落、保存、审校、重索引） |
| 右栏 | 修改 Agent（全局指令 / 自定义 Agent / 槽位）、Chat 助手、设定摘要（世界书） |
| 底部 | 修改要求输入框（改写选中段 / 整章批量改写） |

### 3. AI 章节修改
- **改写选中段**：单段流式改写
- **多段统一改写**：通读所选段落上下文后整体修改，避免前后不一致
- **整章批量改写**：一次调用通读全文后按段落输出，可自动建议新章节名
- **章节感知**：AI 请求中自动携带章节序号与章节名；可单独开关"是否允许 AI 修改章节名"
- 修改后保存自动为标题追加 **【已修改】** 标记（词汇替换除外）

### 4. 总体设定修改（批量修改）
- **关键词模式**：输入关键词与修改要求，仅处理命中的章节
- **全章节逐章模式**：不输关键词，AI 逐章阅读后**自行判断是否需要修改**；判断无需修改则跳过（省时省 token），只修改判定需要的章节
- 修改结果先进入**「待确认」**列表，可逐条/全部保留或放弃，避免误改
- 自动记录**修改历史**，可查看与重新修改
- 每章修改后更新向量记忆（纯代码索引，不耗 token），保证后续章节引用到最新内容
- 提供独立开关：**同步更新世界书**（默认关，省 token；勾选后仅对实际修改章节提取设定）、**同步向量记忆**（默认开）
- 批量修改的**规划与修改阶段**会注入前后章节上下文 + 世界书命中设定 + 已修改章节回顾，保证设定衔接一致

### 5. 文本检索与查找替换
- **文本检索**：纯文本检索关键词出现在哪些章节（含章节标题命中提示），可限定章节范围
- **查找替换**：正文 + 章节标题同步替换，**不自动添加【已修改】标记**，替换后同步向量记忆

### 6. 世界书（Lorebook）设定系统 / 小说转世界书
- 以"设定条目 = 名称 + 触发关键词 + 内容"的方式管理角色 / 地点 / 组织 / 物品 / 种族 / 世界观 / 剧情 / 关系 / 知识书等设定
- AI 修改内容时按**关键词命中**自动读取对应设定，保证不 OOC、不设定冲突（修改阶段用整章内容匹配，章节中后段的关键词也能触发）
- **小说转世界书**：AI 逐章阅读，按所选分类提取设定并**去重合并**（同一实体自动追加内容、更新触发词，发展式更新）；支持 9 类提取分类勾选与章节范围选取
- **总结模板**：详细梳理版 / 简洁版 / 剧情推进版；content 强制总分结构（# 标题 + 1.2.3 列举 + 先概括再 - 细分 + 禁粗体）
- **关键词定向总结**：输入实体名，全文检索相关章节 → AI 通读后总结该实体设定写入世界书
- 支持自动清洗无意义触发词、合并重复条目

### 7. 向量记忆
- 基于 ChromaDB + SentenceTransformer，将章节切块建立向量索引（纯本地计算，不消耗 AI token）
- 检索叠加**关键词精确匹配**，中文词汇可直接命中（辅助语义检索）
- AI 修改时自动注入相关历史记忆，保证全书一致性

### 8. AI 引擎：本地 / 外部
- **本地 Ollama**：调用本机 Ollama（如 deepseek 等模型）
- **外部 OpenAI 兼容 API**：支持多**配置槽位**（如 DeepSeek 官方、火山方舟 Agent Plan 等），每套 Base URL / API Key / 模型 独立保存，可下拉切换；连接检测支持 `/models` 不可用时的自动降级验证
- 顶部状态栏实时显示当前供应商与连接状态

### 9. 其他
- **Prompt 仓库**：保存 / 应用修改要求模板（分类、标签、说明）
- **Agent 设置**：全局指令、自定义 Agent，可保存到槽位复用；每本小说独立
- **审校本章 / 重索引**：单章审校与向量重建
- **导出修改版**：整本导出为 TXT
- **专注模式**：全屏沉浸编辑
- GPU 心跳 / 健康检查（`/api/ai/healthz`）

## 二、环境要求

- Windows 系统
- Python **3.8+**（推荐 Anaconda，如 `chatglm3` 环境 = Python 3.10；`chromadb` 要求 Python ≥ 3.8）
- 依赖清单见 `requirements.txt`
- AI 引擎二选一：
  - 本地：安装 [Ollama](https://ollama.com) 并下载模型（`启动Ollama.bat`）
  - 外部：任意 OpenAI 兼容 API 的 Base URL / Key / 模型名

# 方式一：一键安装（推荐）

## 四、基本用法 / 使用教程

### 1. 启动
双击 **`启动.bat`**，脚本会自动查找 Python、启动 Flask 服务并打开浏览器：

```
http://127.0.0.1:5000
```

### 2. 导入小说
1. 点击左上角 **「📂 导入TXT」**，选择小说文件
2. 等待解析完成（会自动识别章节并建立向量索引；若未安装向量库会给出提示，不影响章节导入）

### 3. 选择章节与查看
- 左侧目录点击章节即可在中间打开
- 支持三种视图：卡片 / 整页 / 对比（diff）

### 4. 单章 AI 修改
1. 在底部"修改要求"输入框填写要求（如：把这段改得更有古风韵味）
2. 方式一：选中某段后点 **「✨ 改写选中段」**
3. 方式二：点 **「🚀 整章批量改写」**（AI 通读全文后按段落输出）
4. 检查修改结果，点击 **「💾 保存本章」** 才会落盘
5. 可选：**「🔍 审校本章」** 审校全章；**「🔄 重索引」** 重建向量

### 5. 总体设定修改（批量）
1. 左侧 **「🛠️ 总体设定修改」** 面板
2. 选择模式：
   - **关键词模式**：填入关键词（逗号分隔，如：哥斯拉,金手指）
   - **全章节模式**：关键词可留空，AI 自行阅读判断
3. 填写修改要求，可设定章节范围
4. 点 **「▶ 开始修改」**，等待逐章处理（面板实时显示 阅读/规划/修改/跳过 进度）
5. 完成后在**「待确认」**列表查看结果，点 **「✅ 保留全部修改」** 或逐条保留/放弃
6. 需要重改某章：在历史/待确认中发起 **「重新修改」**

### 6. 小说转世界书（自动梳理设定）
1. 左侧 **「📚 小说转世界书」** 面板
2. 勾选要提取的**分类**（角色/地点/组织/物品/种族/世界观/剧情/关系/知识书），可「📋 选取章节」或按范围（如 `1-50, 60`）限定
3. 点 **「▶ 开始生成」**：AI 逐章阅读并按所选分类提取设定，去重合并写入世界书
4. 也可在设定摘要面板用 **「🧠 总结该设定」** 针对单个实体做关键词定向总结
5. 右侧 **「📊 设定摘要」** 面板可查看、编辑、测试世界书条目

### 7. 文本检索 / 查找替换
- **文本检索**：输入词汇 → 检索，展示命中章节与上下文（含标题命中标注），可限定章节范围
- **查找替换**：输入查找文本与替换文本 → 「🔍 预览命中」→「⚡ 执行替换」；正文与标题同时替换，不添加【已修改】

### 8. 导出
- 左上角 **「💾 导出修改版」** 导出整本修改后 TXT

### 9. 切换 AI 引擎
- 顶部 **「本地Ollama / 外部API」** 一键切换
- 使用外部 API：`⚙️ 设置 → 外部API` 中管理**配置槽位**

## 六、注意事项（重要）

1. **单章修改后切换章节会丢失未保存的修改**
   - AI 改写/审校的中间结果只存在内存中，**必须点击「💾 保存本章」**才会写入磁盘
   - 在未保存的情况下切换章节、刷新页面或关闭浏览器，修改内容会**全部丢失**
2. **词汇替换不会自动加【已修改】**
   - 查找替换会同步替换正文与标题，但不会给标题追加【已修改】标记
3. **批量修改先确认后生效**
   - 总体设定修改的结果先进入「待确认」，**点「保留」后才写入**；放弃则丢弃
   - 批量修改默认**不同步世界书**（省 token）；需要顺带更新世界书请勾选「同步更新世界书」
4. **向量记忆依赖 chromadb**
   - 未安装 chromadb 时向量检索/记忆功能不可用（章节导入不受影响，会提示 index_warning）；请用 `安装依赖.bat` 安装
   - 向量记忆索引为纯本地计算（不消耗 AI token）；批量面板可单独关闭「同步向量记忆」
5. **AI 修改章节名默认关闭**
   - 需在 设置 → AI 参数 中开启"允许 AI 修改章节名"
6. **本地模型需 Ollama 运行**
   - 切换到「本地Ollama」时需保证 Ollama 服务已启动（`启动Ollama.bat`）且模型已下载，否则报"无法连接"
7. **外部 API 风控与限流**
   - 批量大范围修改时可能触发平台限流/风控（表现为"无法连接到外部API"）；工具内置自动重试与退避
   - NSFW 类内容可能被 API 平台内容风控临时限制，请谨慎使用
8. **数据与隐私**
   - 你导入的小说、API 密钥、向量库等全部存放在 **`data/` 目录**，属本地私密数据，**已通过 `.gitignore` 排除，不会被提交到 Git**
   - 备份/迁移时请整体复制 `data/` 目录
9. **端口占用**
   - 服务默认端口 5000；若被占用可通过环境变量 `PORT` 修改
10. **依赖安装环境**
   - 请确保使用 Python ≥ 3.8（推荐 Anaconda `chatglm3` 环境），否则 chromadb 安装会失败

## 七、项目结构

```
AI-Powered-Smart-Novel-Editor/
├── app.py                    # Flask 后端入口（所有 API 路由）
├── requirements.txt          # Python 依赖
├── 启动.bat                  # 一键启动（自动找 Python、开浏览器）
├── 启动Ollama.bat            # 启动本地 Ollama 服务
├── 安装依赖.bat              # 一键安装依赖（清华镜像）
├── 导入RWKV6模型.bat         # 导入本地 RWKV6 模型（可选）
├── 强制关闭与清理.bat        # 清理残留进程/临时文件
├── config/
│   └── settings.py           # 配置加载 / 默认配置
├── core/
│   ├── tri_ai.py             # AI 三模态（写作/审校/聊天）+ 世界书 + 批量规划
│   ├── external_client.py    # 外部 OpenAI 兼容 API 客户端（多槽位）
│   ├── ollama_client.py      # 本地 Ollama 客户端
│   ├── chapter_parser.py     # 章节解析
│   └── chroma_memory.py      # 向量记忆（ChromaDB + SentenceTransformer）
├── services/
│   ├── novel_service.py      # 小说存储/章节读写/检索/替换
│   └── prompt_service.py     # Prompt 仓库
├── static/
│   ├── index.html            # 前端页面
│   ├── css/style.css         # 样式
│   └── js/app.js             # 前端逻辑
└── data/                     # ⚠️ 运行时数据（不入库）：小说、config.json(API密钥)、向量库等
```
